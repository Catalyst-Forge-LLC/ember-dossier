# EmberDossier site

[FilePress](https://getfilepress.com/) explainer for [emberdossier.com](https://emberdossier.com). Engine from npm: `getfilepress`.

```bash
pnpm install
pnpm dev
pnpm build    # → build/
pnpm ship     # build + wrangler pages deploy (project: emberdossier)
```

If [LocalSlip](https://www.npmjs.com/package/localslip) is installed, this site stays on **5196** as `ember-dossier-site`.

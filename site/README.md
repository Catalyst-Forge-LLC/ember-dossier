# EmberDossier site

FilePress explainer for EmberDossier. Local engine via `link:../../filepress`.

```bash
# once in the engine repo
cd ../../filepress && pnpm install

# in this site
pnpm install
pnpm dev
pnpm build    # → build/
```

If LocalBerth is installed, claim `ember-dossier-site` on port **5189**.
